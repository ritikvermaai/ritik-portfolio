# V36 Corrected Backend Architecture

This build fixes the V36 backend module path/initialization issues found during local startup testing.

## Fixed
- `backend/app.js` now imports `models` from `./models`.
- `backend/app.js` now imports services from `./services/...`.
- `backend/app.js` now imports routes from `./routes`.
- Admin authentication middleware and audit helpers are initialized before any routes use them.
- Removed the stale root `package-lock.json` so `npm install` can generate a lockfile matching the refactored dependencies.

## Start locally

From the project root:

```powershell
npm install
npm start
```

Frontend development:

```powershell
cd frontend
npm install
npm run dev
```

Do not use `npm ci` on this corrected source until a fresh lockfile has been generated by `npm install`.
